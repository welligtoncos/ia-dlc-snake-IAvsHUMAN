# 👋 Bem-vindo ao AI-DLC (AI-Driven Development Life Cycle)! 👋

Vou guiá-lo por um workflow adaptativo de desenvolvimento de software que se adapta de forma inteligente às suas necessidades específicas.

## O que é AI-DLC?

AI-DLC é um processo de desenvolvimento de software estruturado, porém flexível, que se adapta às necessidades do seu projeto. Pense nele como ter um arquiteto de software experiente que:

- **Analisa seus requisitos** e faz perguntas de esclarecimento quando necessário
- **Planeja a abordagem ideal** com base na complexidade e no risco
- **Pula etapas desnecessárias** para mudanças simples, enquanto oferece cobertura abrangente para projetos complexos
- **Documenta tudo** para que você tenha um registro completo de decisões e justificativas
- **Guia você por cada fase** com checkpoints claros e portões de aprovação

### Detalhamento das Fases:

**FASE DE INCEPTION** - *Planejamento e Design da Aplicação*
- **Propósito**: Determina O QUE construir e POR QUÊ
- **Atividades**: Entender requisitos, analisar código existente (se houver), planejar a abordagem
- **Saída**: Requisitos claros, plano de execução, decisões sobre o número de unidades de trabalho para desenvolvimento paralelo
- **Seu Papel**: Responder perguntas, revisar planos, aprovar a direção

**FASE DE CONSTRUCTION** - *Design Detalhado, Implementação e Testes*
- **Propósito**: Determina COMO construir
- **Atividades**: Design detalhado (quando necessário), geração de código, testes abrangentes
- **Saída**: Código funcional, testes, instruções de build
- **Seu Papel**: Revisar designs, aprovar planos de implementação, validar resultados

**FASE DE OPERATIONS** - *Implantação e Monitoramento (Futuro)*
- **Propósito**: Como IMPLANTAR e EXECUTAR
- **Status**: Placeholder para futuros workflows de implantação e monitoramento
- **Estado Atual**: Atividades de build e testes tratadas na fase de CONSTRUCTION

## Princípios-Chave:

- ⚡ **Totalmente Adaptativo**: Cada estágio é avaliado independentemente com base nas suas necessidades
- 🎯 **Eficiente**: Mudanças simples executam apenas estágios essenciais
- 📋 **Abrangente**: Mudanças complexas recebem tratamento completo com todas as salvaguardas
- 🔍 **Transparente**: Você vê e aprova o plano de execução antes do trabalho começar
- 📝 **Documentado**: Trilha de auditoria completa de todas as decisões e mudanças
- 🎛️ **Controle do Usuário**: Você pode solicitar que estágios sejam incluídos ou excluídos

## O Que Acontece a Seguir:

1. **Vou analisar seu workspace** para entender se este é um projeto novo ou existente
2. **Vou reunir requisitos** e fazer perguntas de esclarecimento se necessário
3. **Vou criar um plano de execução** mostrando quais estágios proponho executar e por quê
4. **Você revisará e aprovará** o plano (ou solicitará mudanças)
5. **Executaremos o plano** com checkpoints em cada estágio principal
6. **Você receberá código funcional** com documentação completa e testes

O processo AI-DLC se adapta a:
- 📋 Clareza e complexidade da sua intenção
- 🔍 Estado da base de código existente
- 🎯 Escopo e impacto das mudanças
- ⚡ Requisitos de risco e qualidade
